# Recidivism Dataset - Phase 1 Exploratory Data Analysis

Exploratory Data Analysis on the Rossi Recidivism Dataset (1,445 records)
performed as part of a Data Science project.

## Tasks Completed
- Data loading & inspection
- Basic statistical analysis
- Missing data handling
- Data cleaning & outlier detection
- Data transformation & feature engineering
- Univariate analysis (4 visualizations)
- Bivariate analysis (4 visualizations)
- Multivariate analysis (5 visualizations)

## Tools Used
Python · Pandas · NumPy · Matplotlib · Seaborn · SciPy · Google Colab

## How to Run
1. Open `phase1_eda.ipynb` in Google Colab
2. Upload `recid.csv` when prompted
3. Run all cells
